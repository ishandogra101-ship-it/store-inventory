Section 1

1Overview

Store Inventory is a web app for tracking housekeeping and maintenance consumables. It records every stock-in (received from a supplier), every issue-out (sent to a department or person), and returns (unused stock brought back). All data is shared in real time — anything one user does is instantly visible to everyone else.

The app is split into four areas:

AreaWhat it's for
StockSee current quantities. Items below their minimum threshold are highlighted in amber.
Add Stock / Issue / HistoryRecord new transactions — tabs on the same screen.
StatisticsKPI cards, charts, and Excel export.
SettingsManage the master lists: items, suppliers, and locations.
Sign-in requiredOnly @maruti.co.in email addresses can log in. Your account is shared with everyone on the team — whoever logs in sees the same live data.
Section 2

2First-time Setup

Before you can add stock or issue items, you need a master list of items, suppliers, and locations. Do this once in Settings.

  1. Open Settings (the gear icon in the top bar or the Settings tab on mobile).
  2. Under Items, enter an item name (e.g. Phenyl), choose a unit (Litre, Kg, Pieces…), and optionally set a Min. Threshold — the quantity at which the stock card turns amber as a reorder alert. Click + Add.
  3. Repeat for all items you want to track.
  4. Under Suppliers, add each vendor you buy from (e.g. "ABC Chemicals").
  5. Under Locations, add every department, block, or area that stock gets issued to (e.g. "Block A Washroom", "Building 14 Office").
Duplicate protectionThe app blocks near-duplicates — "ABC Chemicals", "abc chemicals" and "A B C Chemicals" are all treated as the same name. If you see a "Already exists as …" toast, check the existing list before adding.
Section 3

3Stock Dashboard

The Stock tab is your live inventory view. It loads immediately when you open the app.

Search

Type in the search box at the top to filter items by name in real time. The rest of the page updates as you type.

Attention band

Items at or below their minimum threshold appear in an amber-highlighted band at the top. This is your reorder list — the exact items that need action right now.

Stock cards

Each item is shown as a card. The colour of the quantity number and the bar at the bottom tells you the status at a glance:

ColourMeaningWhen it triggers
GreenStock is healthyQuantity is above the minimum threshold
AmberRunning lowQuantity is at or below the minimum threshold
Out of stockNothing leftQuantity is zero
No threshold set?Items without a threshold use a default of 10 units to determine amber vs green. Set a threshold in Settings to tailor alerts to each item.
Section 4

4Adding Stock

Use the Add Stock tab to record stock received from a supplier. This increases the item's current quantity.

  1. Click the Add Stock tab.
  2. Select the Item from the dropdown.
  3. Select the Supplier. (To record a return instead, see Section 5.)
  4. Enter the Quantity received.
  5. Optionally enter a Bill / Invoice number for reference.
  6. Check or adjust the Date (defaults to today).
  7. Click Add to Stock.

The item's stock card updates immediately and a new record appears in the History tab.

Section 5

5Recording Returns

Sometimes stock is issued to a location but not actually used — for example, extra cleaning supplies that come back to the store. This is not a new purchase; it's a return, and it should be tracked separately so your statistics stay accurate.

  1. Click the Add Stock tab.
  2. Select the Item that was returned.
  3. In the Supplier dropdown, choose "Returned (not used)".
  4. The Bill field is replaced by a Returned From location picker — select where the stock came back from.
  5. Enter the Quantity returned.
  6. Click Add to Stock.
Why does this matter?Returns are shown separately in Statistics under the "Returned" KPI and the timeline chart, so you can see the difference between what was genuinely consumed and what was brought back.
Section 6

6Issuing Items

Use the Issue Item tab to record stock going out — sent to a department, person, or location. This decreases the item's current quantity.

  1. Click the Issue Item tab.
  2. Select the Item.
  3. Select the Location the item is going to.
  4. Enter the Quantity.
  5. Enter the Issued To — Name (the person receiving the items). This field is required.
  6. Optionally enter the Employee ID for a more precise record.
  7. Check the Date and click Issue.
Cannot issue more than current stockThe form will block submission if the quantity exceeds what's available. Add stock first, then issue.

Section 9

9Settings

Items

Add, view, and remove the products your store tracks. Each item has a name, a unit (how quantity is measured), and an optional minimum threshold that triggers the amber low-stock alert.

Deleting an item with stockIf an item still shows stock, you must type its exact name in the confirmation dialog to confirm deletion. This prevents accidental removal of active inventory. Transaction history is always kept even after deletion.

Suppliers

The list of vendors that appear in the "Add Stock" supplier dropdown. Removing a supplier does not delete any past transactions — it only removes it from future dropdowns.

Locations

Departments, blocks, or areas that items are issued to or returned from. Same rules as suppliers — removal is non-destructive to history.

Section 10

10Frequently Asked Questions

Can multiple people use the app at the same time?

Yes. The app uses Firebase Firestore for real-time sync. When one person adds stock or issues an item, everyone else's screen updates within seconds — no refresh needed.

What if I accidentally record the wrong quantity?

There is no edit function for past transactions (this is intentional — it preserves an accurate audit trail). To correct a mistake: if you over-issued, add the excess back as a Return. If you under-received, add a new Add Stock entry for the difference. Note both with a comment in the bill/notes field for reference.

I added a supplier called "ABC" but now I can't add "A B C". Why?

The app normalises names by removing spaces and punctuation before checking for duplicates. "ABC", "A B C", "a.b.c" and "A-B-C" all look the same to the duplicate checker. This prevents accidentally having the same vendor under two slightly different names. If you genuinely need a separate entry, use a more distinguishing name (e.g. "ABC Chemicals" vs "ABC Traders").

The stock card for an item shows amber even though I haven't set a threshold.

Items with no threshold use a built-in default of 10 units. If an item naturally runs below 10 and you don't want the alert, set its minimum threshold to 0 in Settings — that disables the alert entirely.

How do I download a copy of all transactions?

Go to Statistics and click Export Excel. This downloads an .xlsx file with every transaction — item, type, quantity, supplier/location, recipient, and date. You can open it in Microsoft Excel or Google Sheets.

Can I delete a location or supplier that was used in past transactions?

Yes. Removing a location or supplier only removes it from the dropdown for future entries. All past transactions that referenced it are kept intact and still show the original name in the History and Statistics views.

I see "Only @maruti.co.in email addresses are allowed" when trying to sign in.

The app is restricted to Maruti Suzuki work email addresses. Make sure you are signing in with your official yourname@maruti.co.in email, not a personal Gmail or other address.

Who do I contact if something is wrong with the app?

Contact your IT administrator or the person who set up the app. They have access to the Firebase console and can investigate data issues or account problems.
