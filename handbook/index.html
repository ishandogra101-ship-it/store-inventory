Section 1

1Overview

Store Inventory is a web app for tracking housekeeping and maintenance consumables. It records every stock-in (received from a supplier), every issue-out (sent to a department or person), and returns (unused stock brought back). All data is shared in real time — anything one user does is instantly visible to everyone else.

The app is organised into tabs. Scroll the tab bar left or right on mobile:

Section 2

2First-time Setup

Before you can add stock or issue items you need a master list of items, suppliers, and locations. Do this once in the Master tab.

  1. Open the Master tab.
  2. Under Items, enter an item name (e.g. Phenyl), choose a unit (Litre, Kg, Pieces…), and optionally set a Min. Threshold — the quantity at which the stock card turns amber as a reorder alert. Click + Add.
  3. Repeat for all items. If you have many items, use Bulk import from Excel / CSV (see Section 10).
  4. Under Suppliers, add each vendor you buy from (e.g. "ABC Chemicals").
  5. Under Locations, add every department, block, or area that stock gets issued to (e.g. "Block A Washroom", "Building 14 Office").
Duplicate protectionThe app blocks near-duplicates — "ABC Chemicals", "abc chemicals" and "A B C Chemicals" are all treated as the same name. If you see an "Already exists" toast, check the existing list before adding.
Section 3

3Stock Dashboard

The Stock tab is your live inventory view. It loads immediately when you open the app and updates in real time as transactions are recorded.

Search

Type in the search box to filter items by name in real time.

Needs Attention band

Items at or below their minimum threshold appear in an amber-highlighted band at the top, sorted by severity. This is your reorder list — the exact items that need action right now. Items with zero stock appear before those that are merely low.

No threshold set?Items without a threshold use a default of 10 units for the amber alert. Set threshold to 0 in the Master tab to disable alerts for that item entirely.
Section 4

4Adding Stock

Use the Add Stock tab to record stock received from a supplier. This increases the item's current quantity.

  1. Click the Add Stock tab.
  2. Select the Item from the dropdown.
  3. Enter the Quantity received.
  4. Select the Source / Supplier. To record a return instead, see Section 5.
  5. Enter the Bill / Invoice number for reference.
  6. Click Add to Stock.

The item's stock card updates immediately and a new record appears in the History tab.

Section 5

5Recording Returns

Sometimes stock is issued to a location but not actually used — for example, extra cleaning supplies brought back to the store. This is not a new purchase; track it as a return so your statistics stay accurate.

  1. Click the Add Stock tab.
  2. Select the Item that was returned.
  3. Enter the Quantity returned.
  4. In the Source dropdown, choose "Returned (not used)".
  5. The Bill field is replaced by a Returned From location picker — select where the stock came back from.
  6. Click Add to Stock.
Why does this matter?Returns are shown separately in Statistics so you can see the difference between what was genuinely consumed and what was brought back.
Section 6

6Issuing Items

Use the Issue Item tab to record stock going out. This decreases the item's current quantity and creates an audit record with the recipient's name and a mandatory reason.

  1. Click the Issue Item tab.
  2. Select the Item.
  3. Enter the Quantity.
  4. Select the Location the item is going to.
  5. Enter the Issued To — Name of the person receiving the items. Required.
  6. Optionally enter the Employee ID for a more precise record.
  7. Enter a Notes / Reason — e.g. "Routine floor cleaning", "Equipment maintenance repair". Required.
  8. Click Issue Item.
Confirmation before every issueAfter clicking Issue Item, a summary popup shows the item, quantity, location, recipient, notes, and your email. Review carefully and click Issue Item to confirm — or ← Edit to go back and fix a mistake. This prevents accidental wrong-quantity entries.
Cannot issue more than current stockThe form blocks submission if the quantity exceeds what is available. Add stock first, then issue.
Section 7

7History

The History tab shows every transaction in reverse-chronological order. Each row shows the item, quantity, supplier / location / person involved, any notes, who created the entry (email), and the timestamp.

Filters

FilterShows
AllEvery transaction including void reversals
Stock InStock received from suppliers
ReturnsUnused stock brought back to store
IssuesStock sent out to locations / people

Exporting

Click the Export button (top-right of the History tab) to download inventory-history-YYYY-MM-DD.xlsx. The file includes every column: Date, Type, Item, Quantity, Unit, Supplier, Bill No, Location, Issued To, Employee ID, Notes, Voided status, and the user who created the entry (email and UID).

Voiding a Wrong Transaction Admin only

If a transaction was entered by mistake, an admin can click the Void button on that row. A confirmation dialog shows the details. On confirming, the system will:

  • Reverse the stock change (e.g. an incorrect issue restores the quantity).
  • Mark the original row with a red VOIDED badge.
  • Create a new REVERSAL entry recording who voided it and when.
Nothing is ever deleted by a VoidBoth the original and the reversal entry stay in the log permanently. Void entries only appear in the All filter view.

Hard Delete Admin only

The trash icon on each row lets an admin permanently remove a transaction record. Stock is not adjusted — hard delete is purely for removing incorrect test or dummy entries. The Activity Log (Logs tab) records every hard delete with the admin's identity.

Hard delete is permanent and does not adjust stockUse Void when you need the stock corrected. Use hard delete only for records that should never have existed (e.g. a duplicate test entry).

Section 10

10Master Tab

The Master tab is where you manage the catalogue of items, suppliers, and locations. All users can access it.

Items

Each item has a name, a unit (how quantity is measured), and an optional Min. Threshold that triggers the amber low-stock alert on the Stock dashboard.

  • Click the pencil icon on any item row to edit its name, unit, or threshold. Changes reflect immediately on the Stock dashboard and all dropdowns.
  • Click the × icon to delete an item. If the item still shows stock, you must type its exact name in the confirmation dialog. Transaction history is always preserved.
Editing names does not change past transactionsTransaction records store the item name at the time of the transaction. Renaming an item only affects future entries and the Stock dashboard — history is never altered.

Bulk Import from Excel / CSV

To load your initial stock data at once, use the Bulk import from Excel / CSV button at the bottom of the Items section.

  1. Click Download template to get a ready-to-fill .xlsx file.
  2. Fill in your items: Item Name, Unit, Initial Stock, Min Threshold.
  3. Save the file and click Bulk import from Excel / CSV.
  4. A preview table shows every row — green New rows will be created, amber Skip rows already exist and will be ignored.
  5. Click Import to confirm. A toast confirms how many items were created.
Column headers are flexibleThe importer accepts variations like "Item", "Name", "Qty", "Quantity", "Threshold", "Min Stock" — case-insensitive. Stick to the template for best results. Bulk import is only available to admins.

Suppliers

The list of vendors that appear in the Add Stock supplier dropdown. Use the pencil icon to rename a supplier; use × to remove it. Removing a supplier only affects future dropdowns — past transactions keep the original name.

Locations

Departments, blocks, or areas that items are issued to or returned from. Same edit and remove controls as suppliers.

Section 11 Admin only

11Settings Tab — Access Control

The Settings tab is visible only to admins. It controls who can sign in to the app — no Firebase Console access is ever required.

Who is an admin?

The person who first sets up access control becomes the initial admin automatically. Admins can promote other users or demote them from the Settings tab.

First-time activation

  1. Sign in to the app. You will see the Settings tab in the navigation bar.
  2. An amber notice informs you that access control is not yet active — any @maruti.co.in account can currently log in.
  3. Enter the first staff member's email and click Add User. You are automatically added as admin at the same time.
  4. Access control is now active. Only users on the approved list can sign in.
Add all staff before activatingOnce you add the first user, access restriction activates immediately. Your own email is added automatically — add all other staff emails before anyone tries to log in.

Adding a user

  1. Go to the Settings tab.
  2. Enter the staff member's @maruti.co.in email.
  3. Tick Make admin if this person should also manage access.
  4. Click Add User.

Removing a user

Click Remove next to any user. They will be signed out automatically the next time they open the app. You cannot remove your own account or the last remaining admin.

Changing admin status

Click Make admin or Remove admin next to any user (except yourself). Admin users can see the Settings tab and manage access; regular users cannot. Only admins can also void transactions and hard-delete records.

Handover when leavingBefore leaving the organisation, promote your successor to admin from the Settings tab. They can then manage the access list themselves — no Firebase Console needed.
Section 12

12Frequently Asked Questions

Can multiple people use the app at the same time?

Yes. The app uses Firebase Firestore for real-time sync. When one person adds stock or issues an item, everyone else's screen updates within seconds — no refresh needed.

What if I accidentally issued the wrong quantity?

Contact an admin — only admins can void transactions. The admin will click Void on the incorrect row in the History tab, which reverses the stock change and creates a permanent REVERSAL record. Both the original and the reversal remain visible forever for audit purposes.

Why is the Notes / Reason field required when issuing items?

Every issue must have a documented business reason (e.g. "Routine floor cleaning — Block A", "Equipment repair workshop"). This creates a clear audit trail of why stock left the store, making it easy to investigate discrepancies later. The reason is stored with the transaction and appears in the History tab and exports.

I added a supplier called "ABC" but now I can't add "A B C". Why?

The app normalises names by removing spaces and punctuation before checking for duplicates. "ABC", "A B C", "a.b.c" and "A-B-C" all look the same to the duplicate checker. If you genuinely need a separate entry, use a distinguishing name (e.g. "ABC Chemicals" vs "ABC Traders").

The stock card shows amber even though I haven't set a threshold.

Items with no threshold use a built-in default of 10 units. If an item naturally runs below 10 and you don't want the alert, set its minimum threshold to 0 in the Master tab — that disables the alert entirely for that item.

How do I download all transactions?

Go to the History tab and click the Export button (top-right). This downloads an .xlsx file with every transaction — item, type, quantity, supplier, location, recipient, notes, voided status, and the user who created the entry. You can also export the full Activity Log from the Logs tab using its own Export button.

Can I delete a location or supplier that was used in past transactions?

Yes. Removing a location or supplier only removes it from future dropdowns. All past transactions that referenced it are kept intact and still show the original name in History and Statistics.

A user left the company. What should I do?

Go to the Settings tab (admin only) and click Remove next to their email. They will be signed out automatically the next time they open the app. Their past transaction records are preserved — removing a user never deletes history.

I see "Your account is not approved" when signing in.

Access control is active and your email has not been added to the approved list yet. Contact your admin and ask them to add your @maruti.co.in email from the Settings tab.

Who do I contact if something is wrong with the app?

Contact your admin (the person who manages the Settings tab). For technical issues, they can contact the person who set up the Firebase project.
